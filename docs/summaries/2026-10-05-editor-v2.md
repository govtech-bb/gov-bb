# Editor v2 in the v2 rewrite

Adds `apps/editor_v2` on `feat/editor-v2`, based on `v2-rewrite`, for authoring
service pages and native v2 forms. Each document has its own browser draft and
undo history. Publishing and application submission are not connected.

The app uses Node 24, pnpm, TanStack Start in SPA mode and Vite. Native routes
replace hash navigation while retaining old bookmarks. Failed saves and
unresolved conflicts block navigation; the root client boundary keeps the
static shell and unknown routes safe to hydrate. Start and Router are pinned
together for the blocked-history restoration fix.

Tests use Vitest and the browser fixtures build with Vite. The retained
regression inputs remain byte-identical. The research archive is omitted and
the guides describe the current app. Workspace integration adds the Nx project,
development command and CI typecheck without changing existing dependency
resolutions.

Validation: 904 tests in 95 files; typecheck, lint, formatting, boundary and
capability checks; production build; seven browser fixture suites and twelve
app browser suites. Static production checks cover assets, fonts, deep links,
hydration, workspace persistence and blocked navigation, with Bun unavailable.
The repository build also passed for all 24 selected projects with `landing`
excluded as directed by the local build instructions.

Static hosting must serve existing assets and rewrite application URLs to
`/_shell.html` with HTTP 200. Keep the same origin to retain existing drafts.
