# Package `nav`: Workspace navigation

Shared rules: [implementation brief](../BRIEF.md). Item status: [tracker](../TRACKER.md).

## Decisions already made for this package

- **root-demo-form (decided with the user):**
  - `/` sends signed-in authors to Services. A new browser never gets a demo form. Old-style browser form drafts are attached only when the browser already has them (`workspace/documents.ts`, `host/govbb-draft.ts`).
  - The browser suites currently open the form editor at `/` and rely on that demo form. Give them an explicit way in that real users never see: a fixture helper in `scripts/browser/` seeds the browser draft (localStorage, through Playwright's `addInitScript` or `evaluate`) and opens the form's own route. Tests then set up their data at the boundary.
  - Update every suite that relies on `/`, and run all 15 local suites. Remember that `scripts/browser/*.mjs` are linted and formatted too.
- **sidebar:**
  - Add `Sidebar` to `src/ui` with Header, Group with a label, Item with its current state, Separator, Empty and Actions.
  - Render one `ServiceNav` from either source, browser drafts or API services, with live titles: a page retitled in the editor shows its new title in the sidebar for both sources.
  - Use the shared 56px Bar for Sidebar.Header so it aligns with the editor toolbar.
  - Reuse the shared `touchTarget` token for sidebar rows and keep row classes in one place.
- **sidebar-state:**
  - One row model holds title, depth, status and kind, built from the API: indented rows with labelled status dots.
  - Join the browser form to its service by `form_id`.
  - The "unsaved" flag comes from a draft registry that the publishing package builds later. Don't build that registry.
- **sidebar-collapse:**
  - The collapsed state is remembered per viewer: localStorage, wrapped in try/catch, and the page renders fine without it. The page gets the width back.
  - Below `lg` the sidebar is a drawer opened from a "Pages" button, reusing SidePanel's drawer.
- **services-memory:**
  - Keep search, category, status, sort and page in the URL through a validated search schema (TanStack Router `validateSearch`), restored on every way back.
  - Put "Create service" in the shared EmptyState.
- **scroll-memory:** restore scroll by path, keep each document's view state, and cap mounted pages to the few most recent.
- **preload:** route loaders prime the service and page queries, links preload on intent (hover and focus), and the sidebar frame draws at once from cached titles.
- Keep the new workspace auth guard (`workspaceAdmission` in `src/auth/session.ts`, used by `routes/_workspace.tsx`).
- If you add or change routes, commit the regenerated `src/routeTree.gen.ts` (regenerated by the build or dev server, never by hand).

## Your items, in a sensible order

### `root-demo-form`: The editor's home opens a browser draft, and a new browser gets a demo form (bug, size S)

- **Why it matters:** Opening the editor's address lands people in “Apply for a permit to play loud music”, a form they never made.
- **Board's fix:** Send / to Services, or to a small home with “Continue where you left off”. Attach old-style form drafts only when the browser has them.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/workspace/workspace.tsx:50-60, 90-99, 234-237`; `src/workspace/documents.ts:157-217`; `src/host/govbb-draft.ts:29-41`
- **Behavior:** / is a dashboard with quick actions and recent activity.

### `sidebar`: The service sidebar is built twice, and the copies already differ (duplicate, size M)

- **Why it matters:** A retitled page shows its new title in browser-draft services and its old one in API services, and every sidebar fix has to be made twice.
- **Board's fix:** Add Sidebar to src/ui (Header, Group with a label, Item with its current state, Separator, Empty, Actions) and render one ServiceNav from either source, with live titles.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/workspace/workspace.tsx:345-407`; `src/workspace/service-pages-nav.tsx:27-58`; `src/workspace/sidebar.ts:4-17`
- **Behavior:** The sidebar has Header, Group, GroupLabel, MenuButton, Separator and Trigger.

### `sidebar-state`: The sidebar hides each page's status, nesting and the service's form (enhancement, size M)

- **Why it matters:** Authors can't see which pages of a live service are still drafts or where a page sits, and can't reach the service's form from it.
- **Board's fix:** One sidebar row model (title, depth, status, unsaved, kind) from the API and the draft registry, with indentation and labelled dots, joining the browser form to its service by form_id.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/workspace/service-pages.ts:7-26`; `src/workspace/service-pages-nav.tsx:34-45`; `src/workspace/remote-page-dialogs.tsx:204, 228-232`
- **Behavior:** Rows carry status and pending badges.

### `sidebar-collapse`: The sidebar can't really collapse, and on phones the page list comes first (ux, size M)

- **Why it matters:** On laptops authors lose width to an empty column, and on phones they scroll past the whole page list to reach the page.
- **Board's fix:** The shared Sidebar remembers when it's collapsed and gives its width to the page. Below lg it becomes a drawer opened from a “Pages” button, reusing SidePanel's drawer.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/workspace/sidebar.ts:4-8`; `src/workspace/workspace.tsx:329-348`; `src/workspace/service-pages-nav.tsx:28-31`
- **Behavior:** The sidebar collapses to icons and becomes a sheet on phones.

### `services-memory`: The services list forgets your search, filters and page (ux, size S)

- **Why it matters:** An author working through one category's services has to filter again after every service they open.
- **Board's fix:** Keep the search, category, status, sort and page in the URL with a validated search schema, restore them on every way back, and put Create service in the empty state.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/workspace/services-list.tsx:114-171, 186-194, 221-224`; `src/routes/_workspace.services.tsx:3`
- **Behavior:** The empty state links to “Create your first one”.

### `scroll-memory`: Going back to a page jumps to the top, and open pages pile up (ux, size M)

- **Why it matters:** Comparing two pages costs the scroll position on every switch, and the tab slows with every page visited.
- **Board's fix:** Key scroll restoration by path, keep each document's view state, and cap mounted pages to the few most recent.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/router.tsx:48`; `src/workspace/workspace.tsx:146-154, 205-216, 487-515`

### `preload`: Opening a service blanks the layout (ux, size M)

- **Why it matters:** Every service open and first page visit feels slow, and the page jumps sideways as the sidebar pops in.
- **Board's fix:** Route loaders that prime the service and page queries, intent preloading on hover and focus, and a sidebar frame drawn at once from cached titles.
- **Where (paths under apps/editor_v2, line numbers as of 531b24bb):** `src/router.tsx:41`; `src/routes/_workspace.services.$serviceId.$documentId.tsx:3`; `src/workspace/workspace.tsx:305-335, 420-424`
- **Behavior:** Preloads on intent, and lists keep their frame while loading.
